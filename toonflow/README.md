# Toonflow - 短剧工作台

## 项目概述

Toonflow 是一款 AI 驱动的短剧创作工作台，提供从小说创作到视频生成的完整流水线。

## 核心功能

### 一、小说管理模块
- AI 小说生成
- 章节管理
- 剧情事件提取

### 二、剧本创作模块
- 故事骨架搭建
- 改编策略制定
- 剧本生成
- 剧本资产提取

### 三、视频生产模块
- 衍生资产分析
- 衍生资产图片生成
- 导演规划
- 分镜表生成
- 分镜面板生成
- 视频生成

## 技术架构

- **UI框架**: Electron + React
- **AI模型**: Vercel AI SDK，支持多供应商
- **技能系统**: 232个动态加载技能文件
- **数据库**: SQLite
- **实时通信**: Socket.io

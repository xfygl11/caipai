# UI更新说明 - 步骤化设计

## 更新目标
根据Toonflow-app的Skills分析，分步骤将用户输入要求添加到原有UI页面中，并添加输出预览区域。

---

## 步骤1/5：项目初始化页 - 新建项目弹窗

### 输入要求（来自script_agent_decision.md）
| 参数 | 必填 | 说明 |
|------|------|------|
| 项目标题 | * | 短剧名称 |
| 计划集数 | * | 总共拆分为几集 |
| 单集时长 | * | 每集目标时长（分钟） |
| 平台规格 | * | 画面比例（竖屏9:16/横屏16:9/方形1:1） |
| 风格定位 | * | 短剧整体风格标签 |
| 付费策略 | 选填 | 前几集免费 |
| 原著范围 | 选填 | 改编覆盖的章节范围 |

### 自动计算
- 台词字数 = 单集时长 × 150字/分钟

### 实现方式
- 点击"新建短剧项目"按钮打开弹窗
- 弹窗包含7个输入字段
- 必填项带*标记

---

## 步骤2/5：剧本生成页 - 添加生成集数选择

### 输入要求（来自script_execution_script.md）
| 参数 | 必填 | 说明 |
|------|------|------|
| 当前集数 | * | 要编写的集数（整数输入） |
| 生成集数 | * | 本次生成几集（整数输入，1-5集） |
| 目标章节 | * | 改编覆盖的章节范围 |
| 画风 | - | 从项目配置自动读取 |

### 自动读取（从项目配置）
- 单集时长（已删除重复显示）
- 画风（从项目配置）

### 实现方式
- 当前集数：整数输入框（如: 2）
- 生成集数：整数输入框，限制1-5集
- 目标章节：输入框，可输入章节范围（如: 第2-3章）
- 画风：只读字段

---

## 步骤3/5：导演规划页 - 添加生成按钮和输出预览

### 输入要求（来自production_execution_director_plan.md）
**用户输入：无**

### 自动读取（从项目配置）
- 剧本内容
- 资产列表

### 输出（scriptPlan）
- 分场汇总表（场次、场景名、台词条数、台词字数、情绪浓度、情绪基调）
- 逐场注意事项（情感砸点、一致性锚点、空间距离、环境音、易错提示）
- 场间过渡（过渡方式、说明）

### 实现方式
- 添加skill和工具标签
- 添加`<scriptPlan>`输出预览区域
- 底部添加"生成导演规划"按钮

---

## 步骤4/5：分镜表页 - 更新为生成模式

### 输入要求（来自production_execution_storyboard_table.md）
**用户输入：无**

### 自动读取（从项目配置）
- 剧本内容
- 导演规划
- 资产列表

### 输出（storyboardTable）
- 场次标题（场景名、参演角色）
- 片段列表（每个片段≤15秒）
- 镜头表格（序号、画面描述、时长、景别、运镜、台词、音效）

### 实现方式
- 页面标题从"分镜表编辑"改为"分镜表生成"
- 添加skill和工具标签
- 添加`<storyboardTable>`输出预览区域
- 镜头编号改为片段编号
- 按钮从"保存分镜"改为"生成分镜表"

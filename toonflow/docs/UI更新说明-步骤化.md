# UI更新说明 - 步骤化设计

## 更新目标
根据Toonflow-app的Skills分析，分步骤将用户输入要求添加到原有UI页面中。

---

## 步骤1/4：项目初始化页 - 新建项目弹窗

### 输入要求（来自script_agent_decision.md）
| 参数 | 必填 | 说明 |
|------|------|------|
| 项目标题 | * | 短剧名称 |
| 计划集数 | * | 总共拆分为几集 |
| 单集时长 | * | 每集目标时长（分钟） |
| 平台规格 | * | 画面比例（竖屏9:16/横屏16:9/方形1:1） |
| 风格定位 | * | 短剧整体风格标签 |
| 付费策略 | 选填 | 前几集免费 |
| 原著范围 | 选填 | 改编覆盖的章节范围 |

### 自动计算
- 台词字数 = 单集时长 × 150字/分钟

### 实现方式
- 点击"新建短剧项目"按钮打开弹窗
- 弹窗包含7个输入字段
- 必填项带*标记

---

## 步骤2/4：剧本生成页 - 添加生成集数选择

### 输入要求（来自script_execution_script.md）
| 参数 | 必填 | 说明 |
|------|------|------|
| 当前集数 | * | 要编写的集数（第1集、第2集...） |
| 生成集数 | * | 本次生成几集（默认3集，最多5集） |

### 自动读取（从项目配置）
- 单集时长
- 画风
- 目标章节（从故事骨架）

### 实现方式
- 在原有"当前集数"和"目标章节"下方添加新字段
- 生成集数提供下拉选择：1集/3集/5集
- 单集时长为只读字段

---

## 步骤3/4：导演规划页 - 添加生成按钮

### 输入要求（来自production_execution_director_plan.md）
**用户输入：无**

### 自动读取（从项目配置）
- 剧本内容
- 资产列表

### 实现方式
- 在原有展示内容上方添加提示：基于剧本自动拆分场次，无需手动输入
- 底部添加"生成导演规划"按钮

---

## 步骤4/4：分镜表页 - 更新为生成模式

### 输入要求（来自production_execution_storyboard_table.md）
**用户输入：无**

### 自动读取（从项目配置）
- 剧本内容
- 导演规划
- 资产列表

### 实现方式
- 页面标题从"分镜表编辑"改为"分镜表生成"
- 添加提示：基于导演规划自动生成，单镜头最长15秒
- 镜头编号改为片段编号
- 删除代码预览区域
- 按钮从"保存分镜"改为"生成分镜表"

## 三、UI功能模块详细流程

### 3.1 小说管理模块

#### 3.1.1 事件提取功能

**用户操作流程**:
1. 进入"小说管理"页面
2. 选择要提取事件的章节
3. 点击"提取事件"按钮
4. 系统后台调用 `POST /api/novel/event/generate`
5. 使用 `event_extraction` 技能
6. 事件列表显示在页面

**后端实现**:
```typescript
// src/routes/novel/event/generateEvents.ts
new u.cleanNovel(concurrentCount).start(allChapters, projectId)
```

**技能文件**: `data/skills/event_extraction.md`

**输出格式**:
```json
{
  "eventId": "uuid",
  "chapterIndex": 1,
  "events": [
    {
      "eventIndex": 1,
      "description": "事件描述（50字以内）",
      "type": "conflict/introduction/development/climax/resolution",
      "characters": ["出场角色"],
      "location": "场景地点",
      "emotion": "主要情绪",
      "keyDialogue": "关键对白"
    }
  ]
}
```

**事件类型**:
| 类型 | 说明 |
|------|------|
| introduction | 介绍性事件，建立背景 |
| conflict | 冲突事件，推动剧情 |
| development | 发展事件，深化关系 |
| climax | 高潮事件，关键转折 |
| resolution | 解决事件，收束剧情 |

### 3.2 剧本创作模块

#### 3.2.1 故事骨架搭建

**用户操作流程**:
1. 进入"剧本创作"页面
2. 点击"搭建故事骨架"
3. 系统调用 `scriptAgent:storySkeletonAgent`
4. 使用技能: `script_execution_skeleton.md`

**技能内容**:
- 故事核设计 (一句话总结 + 爽点 + 金手指)
- 人物小传 (≤4人，大三角核心角色)
- 三幕结构 (每幕功能、核心问题、覆盖章节)
- 付费卡点设计 (按10%/30%/50%/70%/90%比例)
- 股价级反转设计 (全剧约3个)

**输出格式**:
```xml
<storySkeleton>
  <!-- 故事核 -->
  <core>
    <oneLine>一句话总结</oneLine>
    <satisfaction>核心爽点</satisfaction>
    <goldenFinger>金手指及约束</goldenFinger>
  </core>
  
  <!-- 人物小传 -->
  <characters>...</characters>
  
  <!-- 三幕结构 -->
  <structure>...</structure>
  
  <!-- 付费卡点 -->
  <paywall>...</paywall>
  
  <!-- 反转登记表 -->
  <reversals>...</reversals>
</storySkeleton>
```

#### 3.2.2 改编策略制定

**用户操作流程**:
1. 故事骨架完成后
2. 点击"制定改编策略"
3. 系统调用 `scriptAgent:adaptationStrategyAgent`
4. 使用技能: `script_execution_adaptation.md`

**功能**:
- 分析小说与剧本的差异
- 制定删减/改编决策
- 确定世界观呈现策略
- 锁定核心心理级爽点

**输出格式**:
```markdown
# {作品名} - 关键决策记录
---
## 核心改编原则（3-5条）
## 主要删除决策
## 世界观呈现策略
```

#### 3.2.4 剧本资产提取

**用户操作流程**:
1. 剧本生成完成后
2. 点击"提取资产"
3. 系统调用 `extractAssets.ts`
4. 批量处理剧本 (每5集一组)
5. AI识别新资产和已有资产引用

**后端实现**:
```typescript
// src/routes/script/extractAssets.ts
const result = await u.Ai.Text("universalAi").generate({
  tools: { resultTool },
  // 输入: 剧本内容 + 已有资产列表
  // 输出: 新资产列表 + 已有资产引用
})
```

**资产类型**:
| 类型 | 说明 |
|------|------|
| role | 角色资产 |
| tool | 道具资产 |
| scene | 场景资产 |

**输出格式**:
```typescript
// 新资产
{
  name: string,
  desc: string,
  type: "role" | "tool" | "scene",
  scriptIds: number[]
}

// 已有资产引用
{
  name: string,
  scriptIds: number[]
}
```

**核心功能**:
1. `parseFrontmatter()` - 解析技能文件的 YAML frontmatter
2. `useSkill()` - 加载技能并返回工具函数
3. `createSkillTools()` - 创建 `activate_skill` 和 `read_skill_file` 工具

**技能加载流程**:
```
1. 解析 frontmatter
   ├── name: 技能名称
   └── description: 技能描述

2. 扫描技能目录
   ├── workspace: 二级技能目录
   └── attachedSkills: 三级技能目录 (递归)

3. 创建工具函数
   ├── activate_skill: 激活技能
   └── read_skill_file: 读取资源文件
```

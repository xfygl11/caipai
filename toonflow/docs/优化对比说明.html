核心优化内容

新增 AI对话页面

基于 /api/agents/getMemory 和 /api/agents/clearMemory 接口，实现完整的AI对话界面，包含消息气泡、流式输出、快捷建议按钮

新增 视频工作台

基于 /api/production/workbench/* 系列接口，实现视频轨道管理、批量生成、参数配置、状态轮询等完整功能

细化 技能管理

基于 187个技能文件，实现Skills管理页面，支持开关控制、分类筛选、文件路径展示

完善 分镜编辑器

基于 /api/production/storyboard/* 接口，实现分镜表格布局、镜头时长限制提示、XML预览

新增 供应商颜色标记

DeepSeek蓝色、OpenAI绿色、Gemini黄色、Anthropic紫色，方便快速识别不同AI服务商

新增 调试日志页

基于 /api/setting/dev/* 接口，实现API请求日志、响应时间、错误信息的可视化展示

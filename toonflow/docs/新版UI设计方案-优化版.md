Toonflow 短剧工作台 - 新版UI设计方案（优化版）

本文档基于 Toonflow-app 开源项目完整分析，细化UI组件设计，适配全部业务功能模块。

========================================
一、项目架构分析
========================================

1.1 技术栈
- 前端：Electron + React（主仓库分离，本设计聚焦移动端预览）
- 后端：TypeScript + Express.js + Socket.io
- AI：Vercel AI SDK（支持多供应商）
- 数据库：SQLite (Better-SQLite3)
- 技能系统：187个 Markdown 技能文件

1.2 核心功能模块（基于API路由）

| 模块 | 路由前缀 | 功能描述 |
|------|---------|---------|
| 项目管理 | /api/project/* | 创建、编辑、删除项目 |
| 小说管理 | /api/novel/* | 章节CRUD、事件提取 |
| 剧本创作 | /api/script/* | 剧本生成、资产提取 |
| 视频生产 | /api/production/* | 导演规划、分镜管理 |
| 资产生成 | /api/assetsGenerate/* | 衍生资产图片批量生成 |
| 资产库 | /api/assets/* | 角色/场景/道具管理 |
| AI对话 | /api/agents/* | Agent记忆系统 |
| 系统设置 | /api/setting/* | 模型配置、Skills管理 |
| 任务监控 | /api/task/* | 任务队列管理 |
| 视频工作台 | /api/production/workbench/* | 视频生成、轨道管理 |

========================================
六、原子组件规范
========================================

6.1 图标组件 Icon
- 尺寸：20dp（标签）/ 24dp（按钮）/ 32dp（卡片主图标）
- 颜色：onSurfaceVariant（默认）/ primary（激活）/ error（危险）/ success（成功）
- 点击区域：48×48dp

6.2 按钮体系

类型              | 样式                  | 使用场景
-----------------|----------------------|-------------
FilledButton     | primary背景          | 新建项目、生成、确认
OutlinedButton   | outline边框          | 导出、预览、复制
TextButton       | 无背景               | 取消、返回、编辑
IconButton       | 圆形，48dp点击区     | 附件、发送、关闭

6.3 进度组件
- LinearProgressIndicator：批量任务进度
- CircularProgressIndicator：单个加载状态

6.4 输入框 OutlinedTextField
- 圆角：12dp
- 状态：普通/聚焦/错误/禁用
- 支持：placeholder、label、errorText、清除按钮

========================================
七、复合业务组件
========================================

7.1 消息气泡 MessageBubble

用户消息（UserBubble）：
- 背景：primaryContainer
- 文字：onPrimary
- 圆角：topEnd small，其余 large

AI消息（SystemBubble）：
- 背景：surfaceVariant
- 文字：onSurface
- 左侧Bot头像 32dp圆形
- 圆角：topStart small，其余 large

流式状态：
- 显示"AI思考中..." + 环形加载
- 逐字打字动画（间隔30ms）

错误消息：
- 气泡底色：errorContainer
- 下方红色错误文字 + 重试按钮

7.2 聊天输入框 ChatInputArea
- 固定高度：64dp
- 结构：附件按钮 + 多行输入框 + 发送/停止按钮
- 流式生成中：切换为红色停止按钮

7.3 项目卡片 ProjectCard
- 高度：自适应，最小120dp
- 结构：
  1. 标题（项目名称）TitleLarge
  2. 描述 BodyMedium（空则隐藏）
  3. 标签行：题材Chip + 画风Chip
  4. 底部 LabelSmall（创建时间）
- 交互：点击跳转详情，左滑删除

7.4 功能卡片 FunctionCard
- 布局：水平，高度64dp
- 结构：大图标 + 双行文字
- 用途：项目首页快捷入口

7.5 任务进度卡片 ProgressTaskCard
- 结构：
  - 任务名称 TitleSmall
  - 进度条 LinearProgressIndicator
  - 计数文本 LabelMedium（当前/总数）
  - 右侧状态Chip（运行中/成功/失败）

7.6 资产卡片 AssetCard
- 布局：网格 2列/3列自适应
- 结构：缩略图 + 资产名称 + 业务标签
- 交互：点击预览大图，长按操作菜单

7.7 章节条目 ChapterItem
- 布局：单行列表，左右分布
- 结构：章节名称 + 状态Chip
- 状态：待提取/已提取/已生成剧本

7.8 模型配置块 ModelBlock
- 边框：outline，圆角 medium
- 结构：
  - 模型类型下拉框
  - 模型ID输入框
  - 温度/最大长度双列输入
  - 删除按钮

7.9 内部Tab栏 InnerTabBar
- 布局：横向滚动容器
- 背景：surfaceVariant
- 激活：primaryContainer + primary文字

7.10 技能卡片 SkillCard
- 结构：
  - 技能名称 TitleSmall
  - 分类标签 Chip
  - 状态开关 Switch
  - 文件大小 LabelSmall
- 分类颜色：小说/剧本/生产/资产

7.11 Agent状态卡片 AgentStatusCard
- 结构：
  - Agent图标（类型色）
  - 名称 + 状态标签
  - 最后活跃时间
  - 记忆状态指示器

# 附录：剧本生产流程详解（基于Toonflow-app）

## 流水线总览

```
项目初始化(阶段0) → 故事骨架(阶段1) → 改编策略(阶段2) → 剧本编写(阶段3)
```

## 阶段0: 项目初始化（决策层Agent处理）

### 用户需要填写的参数

| 参数 | 说明 | 示例 |
|------|------|------|
| 项目标题 | 短剧名称 | 《凌玄传》 |
| 计划集数 | 总共拆分为几集 | 20集 |
| 单集时长 | 每集目标时长（分钟） | 3分钟 |
| 平台规格 | 画面比例 | 竖屏9:16 |
| 风格定位 | 短剧整体风格标签 | 战神逆袭 |
| 付费策略 | 前几集免费 | 前3集免费 |
| 原著范围 | 改编覆盖的章节范围 | 第1-10章 |

### 自动计算
- 台词字数 = 单集时长 × 150字/分钟 = 3 × 150 = **450字/集**

### 使用的Skill
- `script_agent_decision.md` - 决策层Agent技能指令

### 工具调用
- `get_novel_events(chapterIndexs)` - 校验章节范围
- `deepRetrieve` - 获取历史记忆（用户要求时调用）

---

## 阶段1: 故事骨架（storySkeleton skill）

### 使用的Skill
- `script_execution_skeleton.md` - 故事骨架搭建Agent

### 工具调用
| 工具 | 作用 |
|------|------|
| `get_novel_events(chapterIndexs: number[])` | 获取章节事件表 |
| `get_planData('storySkeleton')` | 读取工作区数据 |

### 用户需要填写
- 章节范围（从阶段0继承）

### 输出格式
```xml
<storySkeleton>
# {作品名} - 故事骨架

## 故事核
> 一句话总结核心吸引力

## 隐线（人物弧）
主角的内在成长轨迹

## 人物小传（≤4人）
【主角】...
【反一号】...

## 三幕结构
第1幕：...
第2幕：...
第3幕：...

## 分集决策
| 集 | 标题 | 章节 | 功能 | 钩子 |
|----|------|------|------|------|

## 付费卡点设计
| 位置 | 内容 | 类型 |

## 股价级反转登记表
| # | 类型 | 预埋集 | 揭晓集 |
</storySkeleton>
```

### 质量门
- 集数×单集时长符合配置
- 章节全覆盖
- 情绪曲线合理

---

## 阶段2: 改编策略（adaptationStrategy skill）

### 使用的Skill
- `script_execution_adaptation.md` - 改编策略制定Agent

### 工具调用
| 工具 | 作用 |
|------|------|
| `get_planData('storySkeleton')` | 读取故事骨架 |
| `get_novel_events(chapterIndexs)` | 获取事件表 |

### 用户需要填写
- 无（自动读取阶段1输出）

### 输出格式
```xml
<adaptationStrategy>
# {作品名} - 关键决策记录

## 核心改编原则
### {原则名}
- ✅ 正面指导：...
- ❌ 负面边界：...

## 主要删除决策
| 被删内容 | 原因 | 替代方案 |

## 世界观呈现策略
- 关键元素出场节奏：...
- 解释度策略：...
- 角色态度锚点：...
</adaptationStrategy>
```

---

## 阶段3: 剧本编写（script skill）

### 使用的Skill
- `script_execution_script.md` - 剧本编写Agent

### 工具调用
| 工具 | 作用 |
|------|------|
| `get_planData('storySkeleton')` | 读取骨架 |
| `get_planData('adaptationStrategy')` | 读取改编策略 |
| `get_script_content(ids)` | 获取上一集剧本（衔接剧情） |
| `get_novel_text(chapterIndex)` | 获取原文 |
| `get_novel_events(ids)` | 获取事件表 |

### 用户需要填写
- 当前集数（第几集）
- 目标章节

### 输出格式
```xml
<scriptItem name="{作品名} EP{NN}：{集标题}">
# {作品名} EP{NN}：{集标题}
# 目标时长：{单集时长}分钟 ≈ {台词字数}字台词
# 平台：{平台规格} | 风格：{风格标签} | 节拍：{节拍概要}

---
## 剧情梗概
...

---
{场号} {场景名} {时间}/{光线}
人物：{人物1} {人物2} 众{身份}若干

△{场景环境、布景的详细描述}
△{人物动作、表情、语气的具体描写}
{人物名}：{对话内容}
OS（{人物名}，{情绪}）：{内心独白}
</scriptItem>
```

### 格式规范
- 场景描述以 `△` 开头
- 场景之间用 `---` 分隔
- 台词格式：`{人物名}：{台词}`
- 内心独白：`OS（{人物}，{情绪}）：{内容}`
- 旁白：`V.S.（{人物}，{情绪}）：{内容}`
